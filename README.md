# Neon Dodge

Мобильная аркада в одном HTML-файле. Управляйте неоновым шаром, собирайте золотые сферы и уклоняйтесь от красных шипов.

## 🎮 Демо

[Играть онлайн](https://ВАШ_НИК.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/)

> Замените ссылку на свою после публикации через GitHub Pages.

## 📱 Управление

- **Ведите пальцем по экрану** — шар следует за пальцем.
- **Собирайте золотые сферы** — +10 очков.
- **Избегайте красных шипов** — при столкновении теряется жизнь.
- У вас **3 жизни**. После потери жизни шар становится неуязвимым на пару секунд.

## ✨ Особенности

- Полностью адаптировано под мобильные экраны
- Работает офлайн — достаточно одного HTML-файла
- Плавное управление касанием
- Вибрация при столкновениях (на поддерживаемых устройствах)
- Сохранение рекорда в localStorage
- Неоновый визуальный стиль, частицы и эффект тряски экрана
- Без внешних библиотек и зависимостей

## 🛠 Технологии

- HTML5 Canvas
- CSS3
- JavaScript (Vanilla JS)
